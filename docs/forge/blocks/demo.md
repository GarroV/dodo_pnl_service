# Блок: demo

## Назначение

Живое демо без регистрации: точка входа, которая сразу показывает наполненный продукт.
Нужно и для показа заказчику, и как постоянная проверка того, что продукт вообще
поднимается и работает на пустом месте.

Выделен отдельно, потому что демо-данные обязаны быть полностью изолированы от
боевых: продукт хранит персональные данные, и смешивать их с показом нельзя ни при
каких обстоятельствах.

## API-контракт

```
manage.py seed_demo --reset    пересоздаёт демо-базу из шаблона и наполняет
GET /demo?key=<ключ>           вход в демо без регистрации
```

Наполнение обязано показывать продукт целиком, а не пустые экраны:

- два юрлица, три точки, около тридцати сотрудников;
- все четыре схемы расчёта и все три регистра учёта представлены;
- два закрытых периода и один открытый — чтобы работали и отчёт расхождений, и
  сверка, и ретро-правка;
- сотрудники и суммы **сгенерированы**, ни одной настоящей записи партнёра.

## Зависимости

Блоки: `payrun` (чтобы демо-периоды были посчитаны), `web` (точка входа).

Внешнее: Faker или аналог для правдоподобных имён; отдельная база
(`DEMO_DATABASE_URL`).

## Definition of Done блока

- [ ] Демо поднимается с нуля одной командой и наполняется
- [ ] Сброс по расписанию возвращает демо к исходному виду без ручных действий
- [ ] Демо всегда на английском, независимо от языка пользователя
- [ ] Тест: демо-база и боевая база — разные, запись в демо не попадает в боевую
- [ ] Тест: в демо-данных нет ни одной строки из эталонной таблицы партнёра
- [ ] Демо-пользователь не может выйти за пределы демо-тенанта
- [ ] Сквозной смоук в демо: ввод часов → расчёт → ведомость → утверждение проходит
