# Библиотеки экрана табеля

Файл `htmx-2.0.10.min.js` лежит в репозитории намеренно и с закреплённой
версией — решение D017.

| что | значение |
|---|---|
| версия | 2.0.10 (последняя стабильная ветки 2.x на 2026-08-07) |
| откуда | `https://unpkg.com/htmx.org@2.0.10/dist/htmx.min.js` |
| sha-256 | `71ea67185bfa8c98c39d31717c6fce5d852370fcdfd129db4543774d3145c0de` |
| лицензия | Zero-Clause BSD |

Почему не с CDN. В npm уже опубликована `4.0.0-beta6`: адрес без пина версии
однажды отдал бы другую мажорную версию, экран сломался бы молча, и виноватым
выглядел бы наш код. Пин в адресе CDN снимает эту опасность лишь наполовину —
остаётся зависимость продукта от чужой доступности на каждой загрузке страницы.

Как обновлять: скачать новый файл, сверить контрольную сумму, положить рядом под
новым именем, поменять ссылку в `templates/timesheets/grid.html`, прогнать
браузерную проверку экрана. Имя файла содержит версию именно для того, чтобы
подмена не прошла незамеченной ни в diff, ни в кэше браузера.

Проверить сумму:

```bash
shasum -a 256 htmx-2.0.10.min.js
```
