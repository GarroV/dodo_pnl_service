{% comment %} Действие — или объяснение, почему его нет (T072). Главное правило блока, ради которого компонент и существует: кнопка не смеет пропасть молча. Исчезнувшая без объяснения кнопка читается как поломка продукта, человек идёт искать, что сломалось, вместо того чтобы попросить того, у кого право есть. Поэтому «показать» и «объяснить отказ» — это одна развилка в одном файле, а не два независимых `{% if %}` на каждом экране, которые однажды разъедутся. Интерфейс серверные проверки не заменяет: адрес действия остаётся рабочим и по-прежнему отвечает 403 роли без права. Прятать адрес значило бы завести третий контур доступа — в разметке, где его никто не проверит. Параметры: allowed право есть; denied текст отказа — тот же, которым ответит сам отказ (`permissions.explain`), а не переписанный своими словами; url, label куда и что нажимать; primary главное действие экрана; note пояснение рядом с кнопкой; inline действие стоит в строке с соседями (ссылками, другими кнопками): и сама форма, и объяснение отказа на её месте остаются строчными. Иначе блок сдвинул бы ряд вниз; hidden_name / hidden_value скрытое поле (например, точка); reason_* поле обязательной причины. Причина здесь — не «уточнение по желанию», а условие действия: обратимость важнее строгости (конституция, D021), и откат без записанной причины через полгода не объяснить. {% endcomment %}{% if allowed %}
