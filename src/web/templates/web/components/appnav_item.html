{% load ui %}{% comment %} Пункт навигации шапки: ссылка — или не ссылка, если человек уже здесь. Ждёт в контексте `section_url` (куда ведёт) и `section_label` (что написано). Отдельным компонентом, а не шестью копиями в шапке: копия инварианта разъезжается тихо. Инвариант тут один и он же живёт у переключателя разреза ведомости — **текущее значение не ссылка вовсе**. Ссылка на страницу, которая уже открыта, обманывает дважды: мышь обещает переход, которого не будет, а клавиатура и экранный диктор перечисляют её наравне с остальными, не сообщая, где человек находится. Отсюда `span` и `aria-current="page"`. Как определяется «уже здесь»: по корню адреса, а не по совпадению страницы целиком (фильтр `in_section`). Иначе выделение пропадало бы на каждом вложенном экране — на следе расчёта, в табеле, на карточке счёта, — и пункт, потерявший выделение, читается как «вы ушли из раздела», хотя человек внутри него. {% endcomment %}{% if request.path|in_section:section_url %}{{ section_label }}{% else %}{{ section_label }}{% endif %}
