{% load ui %}{% comment %} Пункт навигации шапки: ссылка — или не ссылка, если человек уже здесь. Ждёт в контексте `section_url` (куда ведёт), `section_label` (что написано) и необязательное `section_waiting` — сколько работы ждёт человека в этом разделе. Счётчик рисуется, только когда работа есть. Ноль не показывается вовсе, и это не экономия места: «Инбокс документов · 0» сообщает «здесь очередь, и она пуста», а человеку нужно обратное — чтобы очередь бросалась в глаза, только когда в ней что-то лежит (правило модуля 10 эталона дословно). Отсюда и условие на само число, а не на его наличие в контексте. Отдельным компонентом, а не шестью копиями в шапке: копия инварианта разъезжается тихо. Инвариант тут один и он же живёт у переключателя разреза ведомости — **текущее значение не ссылка вовсе**. Ссылка на страницу, которая уже открыта, обманывает дважды: мышь обещает переход, которого не будет, а клавиатура и экранный диктор перечисляют её наравне с остальными, не сообщая, где человек находится. Отсюда `span` и `aria-current="page"`. Как определяется «уже здесь»: по корню адреса, а не по совпадению страницы целиком (фильтр `in_section`). Иначе выделение пропадало бы на каждом вложенном экране — на следе расчёта, в табеле, на карточке счёта, — и пункт, потерявший выделение, читается как «вы ушли из раздела», хотя человек внутри него. {% endcomment %}{% load i18n %}{% translate "ждёт работы" as waiting_hint %}{% if request.path|in_section:section_url %}{{ section_label }}{% if section_waiting %}{{ section_waiting }}{% endif %}{% else %}{{ section_label }}{% if section_waiting %}{{ section_waiting }}{% endif %}{% endif %}
