{% comment %} Поле формы: подпись и ввод одной парой. Подпись обязательна везде, где ввод не подписан соседним текстом: без `label` поле недоступно с клавиатуры для экранного диктора, а щелчок по подписи не ставит курсор. `id` поэтому тоже обязателен — он и связывает пару. Параметры: id, name обязательные; label подпись; пусто — подписи нет (поле причины в ведомости: колонка узкая, а смысл поля виден из соседней кнопки); type text (по умолчанию), password, file; value, placeholder начальные значение и подсказка; required обязательность на стороне браузера — не вместо серверной проверки, а до неё; stacked подпись отдельной строкой (формы-карточки входа); accept, autocomplete, autofocus, help.
