{% extends "web/print/base.html" %}{% load i18n %} {% block content %} {% comment %} Расчётный листок (T187, issue #184, эталон «Печатные формы»). Один человек — один лист: позиций у строки ведомости единицы, и делить их по листам не приходится. Если однажды схем станет столько, что позиции не влезут, это увидит смоук печати — он проверяет не «страница открылась», а что ни один элемент не вышел за край листа. Главное здесь — оговорка про бруто. В Сербии договариваются о сумме на руки, а бруто, налог и взносы считаются от неё: у человека их не забирают. Числа без этой фразы читаются как удержание из зарплаты, и человек приходит спрашивать, куда делись деньги, которых он не терял. Номера банковского счёта на листке нет намеренно: в схеме его нет, а выдуманный счёт хуже отсутствующего — по нему пойдут искать деньги. См. журнал блока. {% endcomment %}
