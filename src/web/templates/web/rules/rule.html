История стоит между действующим значением и формой намеренно — тем же порядком и по той же причине, что в карточке сотрудника: человек, собравшийся менять правило, сначала видит, что было и с какого числа. Без этого «действует с» набирается наугад. Значение вводится тем видом поля, какого оно типа сейчас: список — там, где допустимое перечислено самими правилами страны (мера работы, схема расчёта), «да/нет» — у выключателя, обычное поле — у остального. Свободный ввод там, где набор ограничен, означает опечатку, которая меняет деньги молча. Кнопки «удалить версию» нет: правило не отменяют задним числом, его заводят заново с новой датой. Иначе исчезнувшая версия унесла бы с собой объяснение того, почему закрытый месяц посчитан именно так. {% endcomment %} {% block title %}{{ heading }}{% endblock %} {% block content %}
