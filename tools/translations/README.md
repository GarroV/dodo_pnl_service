# Таблицы переводов

Вход для `tools/apply_translations.py`. Формат — `{"русская строка": {"en": "…", "sr": "…"}}`.

```bash
python tools/apply_translations.py tools/translations/*.json
rm src/locale/*/LC_MESSAGES/django.mo        # иначе сборка сочтёт .mo свежим
python manage.py compilemessages
```

Почему таблицы лежат в репозитории, а не собираются на коленке в момент правки.
Каталог `.po` — файл машинной сборки: `makemessages` переписывает его целиком,
и по нему невозможно понять, какие строки человек перевёл осознанно, а какие
достались от похожей строки автоматом. Таблица — наоборот, ручной документ: её
можно прочитать, сверить с оригиналом и обсудить, не разбирая тысячу строк
каталога.

- `t102-guessed.json` — разбор T102: 34 строки в каждом каталоге, которым
  `makemessages` перенёс чужой перевод от похожей строки, а пометку `fuzzy`
  потом сняли, не поправив текст. Отсюда `Payroll calculation: not calculated
  yet` над полной ведомостью на главном экране демо.
